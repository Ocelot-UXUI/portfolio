# Runtime Configuration Pattern

> 来源：Figma `GRkvwNuoeXDYxS7yJ3Bpru` / 节点 `467:7514`
> 适用范围：CNAP 应用下的运行配置、资源调度和容器配置页面。

## 页面结构

1. 面包屑导航栏。
2. 页面标题行：`工作负载`、当前应用名称和状态标签。
3. 配置分栏：左侧配置目录，右侧主配置内容。
4. 主配置内容由大分组组成，例如 `容量与变更`、`资源调度`。
5. 每个大分组由连续的 setting list 组成，setting row 之间用分隔线区分。

## 尺寸关系

| 区域 | 规格 |
|---|---:|
| 主配置内容示例宽度 | 815px |
| 主配置内容左右内缩 | 16px |
| 大分组标题到列表 | 34px 垂直间隔 |
| 大分组之间 | 16px |
| 普通设置项 | 64px 或按内容自适应 |
| 带一行子配置的设置项 | 84px |
| 带两行数字配置的设置项 | 118px |
| 带硬性/软性规则的设置项 | 278px |
| 设置项左图标 | 22px × 22px |
| 设置项右控件 | 距内容右边 16px |

## 设置项规则

- 设置项标题与左侧图标在同一基线区域内。
- 复杂设置项的说明文字放在标题下方，使用 `12px / 18px`。
- 子设置相对父设置向右缩进 `16px`，示例中从 `x=16px` 增加到 `x=32px`。
- 数字输入框与单位横向排列，输入框默认宽度 `100px`，单位与输入框间距 `8px`。
- 开关固定靠右对齐，避免随左侧说明文字宽度移动。
- 每个 setting list 默认有底部分隔线；分组的最后一项可以不显示分隔线。

## 资源调度分组

资源调度至少支持以下配置项：单节点副本数、节点架构选择、节点标签选择、节点亲和性、Pod 亲和性、Pod 反亲和性。

亲和性类配置包含两种子规则：

- `硬性要求（必须满足）`：必须满足条件，使用“添加条件组”操作。
- `软性偏好（优先满足）`：尽量满足条件，使用“添加偏好规则”操作，并可配置权重。

## 组件组合规则

- 常规组件使用中号，即默认尺寸。
- 控件推荐宽度为 `80px`、`100px`、`160px`。
- 单行组件组合中，多组件之间、组件与文本之间使用 `8px` 间距；表格单元格不适用此规则。
- 不要为了填满横向空间放大控件；右侧控件应保持设计稿推荐宽度。

## 实现约束

- 后续配置页优先复用 `runtime-page`、`runtime-layout`、`runtime-section`、`runtime-setting-row` 结构。
- 新增字段应优先添加到对应 setting list，不要重新创建一套表单网格。
- 如果字段说明超过一行，应增加该 setting row 的高度，不得压缩行高或覆盖相邻内容。
- 窄视口下允许隐藏右侧目录，但不得让主配置卡片横向溢出。
