# CNAP 表单项 Agent Harness（公开展示版）

> 来源：设计规范中的只读预览、弹窗编辑和复杂配置三类场景。本文只保留可复用的交互判断，不包含业务数据、人员信息或精确视觉参数。

## 使用顺序

1. 确定页面属于只读预览、弹窗编辑还是复杂配置。
2. 选择对应的字段结构和布局。
3. 检查空值、禁用、说明、错误和多层级状态。
4. 用真实页面验收输出；有业务例外时交给设计或产品确认。

## 只读预览

- 用标签和内容展示当前值，不用输入框形态暗示可编辑。
- 单列、双列或多列的选择服从信息长度与阅读顺序。
- 混合布局中，相同列数的行连续排列。

## 弹窗编辑

- 普通字段采用上标题、下控件；开关采用左标题、右开关。
- 已配置且不可再次编辑的字段保留值并置灰。
- 空字段的提示写明对象，例如“请选择生效环境”；非必填字段标明“可选”。
- 字段说明在标题下方换行展示；错误反馈贴近对应控件。

## 复杂配置

- 数值、单选和开关等窄控件优先考虑左右布局。
- 文本、多选、表单组和表格等宽内容采用上下布局。
- 父子字段保持层级可辨；动态新增项延续所在区域的排列规则。

## 待确认

- 业务页面的例外布局、动态项的删除和保存时机，由设计与产品确认后再固化。
- 未定义的细节不可仅凭单个示例推断为全局规则。
