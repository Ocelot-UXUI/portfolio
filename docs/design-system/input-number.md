# InputNumber 数字选择器规范

> 来源：Figma 文件 `GRkvwNuoeXDYxS7yJ3Bpru`，节点 `554:18151`
> 适用范围：运行配置中的实例数量、资源规格、时间和其他数值输入。

## 基础规格

| 属性 | 值 |
|---|---|
| 尺寸 | 136px × 32px |
| 圆角 | 8px |
| 默认背景 | `#FFFFFF` |
| 默认边框 | `1px solid #D9D9D9` |
| 默认文字 | `#181818`，PingFang SC Regular 14px/22px |
| 输入区域 | 左右 padding 10px / 6px |
| 箭头区域 | 28px 宽，使用上下分隔线 |

## 状态

### Default/Default

- 白色背景。
- `#D9D9D9` 边框。
- 数值文字使用 `#181818`。

### Default/Disabled

继承自上级配置、当前层级不可覆盖时使用这个状态：

- 背景：`#F7F7F7`。
- 边框：`1px solid #D9D9D9`。
- 数值文字：`#BFBFBF`。
- 不显示可操作的上下箭头区域。
- 原生输入必须设置 `disabled`，不可输入、聚焦或修改。

### Default/BtnDisabled

- 白色背景。
- 输入文字仍为 `#181818`。
- 右侧箭头区域显示为禁用按钮。
- 只有设计明确要求保留箭头区域时使用；继承态不能使用此状态。

## 实现约束

- 所有数值字段使用 `input type="number"`，保留 `min` 等业务约束。
- 页面通用组件统一使用 `.cnap-input`，不得用普通文本输入框模拟数字选择器。
- 带单位的字段将单位放在输入框外部；输入框本身仍保持 32px 高度和统一状态。
- 不通过 `opacity` 模拟禁用态，必须同步 `disabled`、背景、边框和文字颜色。
